Ler `design-system/readme.md` e depois explorar os arquivos que a tarefa pedir:
- `design-system/tokens/` para cores, tipografia, espaçamento, raios, sombras e motion.
- `design-system/components/<grupo>/<Componente>.prompt.md` para o uso de cada componente.
- `design-system/guidelines/` para os cards de fundamentos (cores, tipo, marca, voz).
- A seção "Design system" do `CLAUDE.md` para as regras do projeto.

Código de produção: importar `design-system/styles.css`, reusar os componentes e usar só tokens.
Artefato visual avulso (mock, slide): copiar os assets necessários e gerar HTML estático.

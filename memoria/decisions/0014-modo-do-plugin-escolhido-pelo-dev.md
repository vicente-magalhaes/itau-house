# 0014: O dev escolhe o modo do plugin

## Rule

- O dev escolhe o modo do plugin: proativo, perguntar antes ou sob demanda (`/itau-house`). O padrão está na 0017.

## Decision

O dev escolhe o modo do plugin: proativo, perguntar antes ou sob demanda (`/itau-house`). Motivo: busca automática pode soar invasiva para parte das pessoas. O aviso aparece no agente de código do dev, ao reconhecer a intenção de criar um ativo. Fecha A-02. Modo padrão: perguntar antes (D-17).

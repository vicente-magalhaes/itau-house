# 0009: Repositório privado, limpo antes da banca

## Rule

- Repositório privado durante o desenvolvimento. Antes da banca, fica só o código e uma apresentação enxuta.

## Decision

Repositório privado durante o desenvolvimento. Antes da banca, limpar para ficar só o código e uma apresentação enxuta.
